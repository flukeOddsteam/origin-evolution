# ORIGIN — Evolution Idle

เกมต้นแบบแนว Idle / Incremental ที่พัฒนาต่อจากไอเดีย “วิวัฒนาการจากชีวิตแรกเริ่มสู่อารยธรรมระหว่างดาว”

## วิธีเปิดเล่น

**ไม่ต้องติดตั้งอะไร:** ดับเบิลคลิก `index.html` แล้วเปิดด้วย Chrome หรือ Edge รุ่นใหม่

ถ้าเบราว์เซอร์บล็อก JavaScript modules เมื่อเปิดจาก `file://` ให้ใช้ local server:

```bash
cd ORIGIN-Evolution-Idle
python3 -m http.server 8000
```

จากนั้นเปิด <http://localhost:8000>

หรือถ้ามี Node.js:

```bash
npx serve .
```

## ระบบที่มีในเวอร์ชันนี้

- 12 ยุค ตั้งแต่กำเนิดชีวิต เซลล์ สิ่งมีชีวิตหลายเซลล์ มนุษย์ เกษตรกรรม อุตสาหกรรม ดิจิทัล ไปจนถึงอารยธรรมระหว่างดาว
- ทรัพยากร 4 ประเภท: DNA, พลังงาน, ประชากร และความรู้
- อัปเกรดการผลิตทรัพยากรแบบ Idle
- สิ่งมีชีวิตที่ทยอยค้นพบตามยุค
- ระบบกลายพันธุ์เพื่อเพิ่มผลผลิต
- แผนผังเทคโนโลยีและโบนัสถาวร
- ค่าระบบนิเวศเชิงเกม: ความหลากหลายทางชีวภาพ ภูมิอากาศ และพื้นที่อยู่อาศัย
- Offline progress สูงสุด 8 ชั่วโมง
- บันทึกอัตโนมัติใน `localStorage`, ส่งออกและนำเข้าเซฟ
- Prestige / เริ่มวัฏจักรใหม่หลังปลดล็อกยุคอวกาศ
- Responsive layout สำหรับจอคอมและมือถือ

## โครงสร้างโปรเจกต์

```text
ORIGIN-Evolution-Idle/
├── index.html
├── src/
│   ├── data.js       # ข้อมูลยุค สิ่งมีชีวิต อัปเกรด เทคโนโลยี
│   ├── engine.js     # ระบบเกม การผลิต การเซฟ และวิวัฒนาการ
│   ├── main.js       # UI และ event handlers
│   └── styles.css    # ธีมและ responsive layout

├── docs/             # เอกสารออกแบบเพิ่มเติม
├── README.md
├── CHANGELOG.md
├── LICENSE
└── .gitignore
```
