# ORIGIN — Evolution Simulator

เกมจำลองวิวัฒนาการแบบ Real-time: ทุกจุดบนแผนที่คือสิ่งมีชีวิตจริงที่มียีนของตัวเอง ว่ายน้ำ เดิน หาอาหาร หนีผู้ล่า สืบพันธุ์ กลายพันธุ์ และตาย สายพันธุ์ใหม่เกิดขึ้นเองจากการคัดเลือกโดยธรรมชาติ จนวันหนึ่งเผ่าพันธุ์ผู้มีปัญญาตั้งถิ่นฐาน สร้างเมือง และส่งจรวดออกสู่อวกาศ

ผู้เล่นทำหน้าที่ **ผู้วางแผนวิวัฒนาการ** — ไม่ได้ควบคุมสิ่งมีชีวิตทีละตัว แต่เปลี่ยนเงื่อนไขของโลก กำหนดแรงคัดเลือก และตัดสินใจว่าจะปลดล็อกยุคใหม่เมื่อไร

## วิธีเปิดเล่น

เกมใช้ JavaScript modules จึงต้องเปิดผ่าน local server:

```bash
cd ORIGIN-Evolution-Idle
python3 -m http.server 8000
# เปิด http://localhost:8000
```

หรือ `npx serve .`

## เผยแพร่เป็นเว็บให้คนอื่นเล่น

```bash
npm install
npm run build        # ได้โฟลเดอร์ dist/
```

- `dist/` คือเว็บ static พร้อมอัปโหลด (index.html, game.js, styles.css, three.min.js) ไม่ต้องมีเซิร์ฟเวอร์หลังบ้าน และไม่พึ่ง CDN
  - **Netlify Drop**: ลากโฟลเดอร์ `dist` ไปวางที่ app.netlify.com/drop
  - **GitHub Pages**: push เนื้อหาใน `dist/` ขึ้น branch `gh-pages` แล้วเปิด Pages ใน Settings
  - **Cloudflare Pages / Vercel / itch.io (HTML5)**: อัปโหลดโฟลเดอร์หรือ zip ของ `dist/`
- `dist/origin-single.html` คือทั้งเกมในไฟล์เดียว ส่งให้เพื่อนแล้วดับเบิลคลิกเปิดได้เลย
- เซฟของผู้เล่นแต่ละคนเก็บในเบราว์เซอร์ของเขาเอง
- `npm run preview` สร้างแล้วเปิดดูที่ http://localhost:8000

## ใหม่ในเวอร์ชัน 0.5

- **มุมมองดาวเคราะห์** (แบบ The Universim) — โลกทั้งใบเป็นดาวทรงกลมลอยในอวกาศ มีบรรยากาศ เมฆ ดวงอาทิตย์ ดวงจันทร์ และเส้นแบ่งกลางวัน–กลางคืน ซูมจากวงโคจรลงไปถึงสิ่งมีชีวิตแต่ละตัว
- **มุมมอง 3 มิติ** (Three.js) — ภูมิประเทศ ภูเขา ทะเล แม่น้ำ ป่า และเมืองเป็น 3D, สิ่งมีชีวิตทุกกลุ่มเป็นโมเดล low-poly ที่เคลื่อนไหวได้
- สลับ ดาว/3D/2D ได้ด้วยปุ่มมุมขวาบนหรือคีย์ `V` · หมุนกล้องด้วยคลิกขวา, Shift+ลาก หรือ `Q`/`E`
- มุมมอง 3D โหลด Three.js r128 จาก cdnjs จึงต้องต่ออินเทอร์เน็ต ถ้าโหลดไม่ได้เกมจะใช้แผนที่ 2D แทน

## ใหม่ในเวอร์ชัน 0.4

- สิ่งมีชีวิต 32 กลุ่ม ตั้งแต่จุลชีพจนถึงมนุษย์ (ปลา ฉลาม วาฬ แมลง กบ ไดโนเสาร์ นก ช้าง เสือ หมี ฯลฯ) ทุกกลุ่มเกิดจากยีน ไม่ได้กำหนดไว้ล่วงหน้า
- ภาพเวกเตอร์ละเอียด เคลื่อนไหวได้ มีเงาและลวดลายประจำสายพันธุ์
- ไบโอม 15 แบบ แม่น้ำ แนวปะการัง ป่าเคลป์ พืชรายต้น กลางวัน–กลางคืน เมฆ ฝน หิมะ
- สารานุกรมสิ่งมีชีวิต (แท็บคลังประวัติศาสตร์)

## สิ่งที่มีตั้งแต่เวอร์ชัน 0.3

**โลกที่มีชีวิต**
- สิ่งมีชีวิตเป็นรายตัว (agent-based) สูงสุดราว 2,000 ตัว แต่ละตัวมียีน 13 ตัว: ขนาด ความเร็ว ระยะรับรู้ อาหาร (พืช↔เนื้อ) ถิ่นอาศัย (น้ำ↔บก) อุณหภูมิที่ชอบ สติปัญญา ความซับซ้อนของร่าง อัตราสืบพันธุ์ อายุขัย เกราะ เลือดอุ่น ปีก
- พฤติกรรม: สำรวจ หาแหล่งอาหารที่ดีที่สุดในระยะรับรู้ ไล่ล่าเหยื่อที่เล็กกว่า หนีผู้ล่า อพยพ
- พลังงานและเมแทบอลิซึม: ตัวใหญ่ เร็ว ฉลาด = ใช้พลังงานมาก ประชากรเพิ่มหรือลดตามอาหาร พลังงาน และอายุ
- การสืบพันธุ์พร้อมการกลายพันธุ์ เมื่อยีนห่างจากต้นสายมากพอจะแตกเป็นสายพันธุ์ใหม่ มีต้นไม้วิวัฒนาการให้ดู
- ภูมิประเทศจาก procedural noise: ทะเลลึก ทะเลตื้น ชายหาด ที่ราบ ที่สูง ภูเขา อุณหภูมิตามละติจูดและความสูง
- พืช/แพลงก์ตอนเติบโตแบบ logistic ถูกกิน งอกใหม่ และแผ่ขยายจากชายฝั่งเข้าสู่ทวีปเมื่อถึงยุคพิชิตผืนดิน
- เหตุการณ์ธรรมชาติ: ยุคน้ำแข็ง โลกร้อน สาหร่ายเบ่งบาน โรคระบาด อุกกาบาต
- อารยธรรม: แคมป์ → หมู่บ้าน → เมือง → นคร → มหานคร มีไร่นา ถนน การล่าสัตว์ป่า การอพยพ มลพิษ และท่าอวกาศ

**การควบคุม**
- ความเร็วจำลอง ⏸ 1× 3× 10× 30× (คีย์ Space, 1–4) ซูม/เลื่อนแผนที่ แผนที่ย่อ
- คลิกสิ่งมีชีวิตเพื่อดูยีน สถานะ พลังงาน อายุ และกดติดตามด้วยกล้อง
- เครื่องมือบนแผนที่: ปลูกอาหาร ปล่อยสายพันธุ์ อุกกาบาต ทำให้โลกเย็นลง/อุ่นขึ้น
- สถิติประชากรสดแยกตามห่วงโซ่อาหาร (กินพืช / กินทั้งพืชและสัตว์ / ผู้ล่า)

**เมนู**
| เมนู | ใช้ทำอะไร |
|---|---|
| อัปเกรด | ปรับเงื่อนไขของโลก เช่น พืชโตเร็วขึ้น เมแทบอลิซึมประหยัดขึ้น |
| สิ่งมีชีวิต | สายพันธุ์ที่มีชีวิต ลักษณะเฉลี่ย กราฟประชากร และต้นไม้วิวัฒนาการ |
| กลายพันธุ์ | อัตรากลายพันธุ์ แรงคัดเลือกแบบกำหนดทิศทาง รังสีเร่งกลายพันธุ์ และยีนเฉลี่ยของโลก |
| เทคโนโลยี | ใช้ความรู้จากถิ่นฐานเพื่อพัฒนาอารยธรรม |
| โลก / ระบบนิเวศ | อุณหภูมิ ความหลากหลาย พืช ไร่นา มลพิษ ห่วงโซ่อาหาร และบันทึกเหตุการณ์ |
| คลังประวัติศาสตร์ | ยุคที่ผ่านมา สถิติ และสายพันธุ์ที่สูญพันธุ์ |
| เริ่มวัฏจักรใหม่ | รีเซ็ตเป็นดาวดวงใหม่เพื่อรับโบนัสถาวร หลังถึงยุคอวกาศ |

**Idle**
- เมื่อสลับแท็บ โลกยังเดินต่อ (ตั้งค่าได้)
- เมื่อกลับมาเปิดใหม่ เกมจำลองย้อนหลังสูงสุด 10 นาทีจำลอง และจ่ายทรัพยากรส่วนที่เหลือ (สูงสุด 8 ชั่วโมง) พร้อมสรุปว่าเกิดอะไรขึ้นระหว่างที่ไม่อยู่
- บันทึกอัตโนมัติใน `localStorage` ทุก 20 วินาที ส่งออก/นำเข้าเซฟได้

## โครงสร้างโปรเจกต์

```text
ORIGIN-Evolution-Idle/
├── index.html
├── src/
│   ├── sim/
│   │   ├── genes.js   # จีโนม 13 ยีน การกลายพันธุ์ ระยะห่างทางพันธุกรรม การตั้งชื่อ
│   │   ├── archetypes.js # จำแนกกลุ่มร่างกายจากยีน และแม่แบบการแผ่กระจายพันธุ์
│   │   ├── world.js   # ภูมิประเทศ แม่น้ำ ความชื้น ไบโอม อุณหภูมิ พืช ไร่นา
│   │   ├── sim.js     # สิ่งมีชีวิตรายตัว พฤติกรรม การเกิด/ตาย การแตกสายพันธุ์ เหตุการณ์
│   │   ├── civ.js     # ถิ่นฐาน เมือง ไร่นา มลพิษ จรวด
│   │   └── eras.js    # ขีดจำกัดทางชีววิทยาของแต่ละยุค
│   ├── data.js        # ยุค เป้าหมาย อัปเกรด เทคโนโลยี เครื่องมือ
│   ├── game.js        # ทรัพยากร ความก้าวหน้า การเซฟ prestige
│   ├── render.js      # วาดภูมิประเทศ ไบโอม พืช ท้องฟ้า และอารยธรรมบน canvas
│   ├── creatures.js   # ภาพเวกเตอร์ 2D ของสิ่งมีชีวิตทั้ง 32 กลุ่ม
│   ├── render3d.js    # มุมมอง 3D และดาวเคราะห์ (Three.js): ภูมิประเทศ อวกาศ instancing
│   ├── models3d.js    # โมเดล low-poly 3D ของสิ่งมีชีวิตทั้ง 32 กลุ่ม
│   ├── chart.js       # กราฟประชากรสด
│   ├── main.js        # UI, game loop, input
│   └── styles.css
├── tools/headless.mjs # รันระบบจำลองใน Node เพื่อตรวจสมดุล
├── tools/build.mjs    # สร้างเว็บ static ลง dist/ (npm run build)
├── vendor/three.min.js # Three.js r128 (MIT) สำหรับเวอร์ชัน static
├── docs/GAME_DESIGN.md
└── CHANGELOG.md
```

## ทดสอบสมดุลแบบ headless

```bash
node tools/headless.mjs 30000 "1500:1,4000:2,7000:3,12000:4"
```

พิมพ์ประชากร สายพันธุ์ ยีนเฉลี่ย และเหตุการณ์ทุก 1,500 tick (30 tick = 1 วินาทีจำลอง)
